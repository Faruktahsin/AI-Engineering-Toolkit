# AI Engineering Toolkit: Governance Model

## 1. Overview
The AI Engineering Toolkit is an open-source project governed by the **Architecture Council** and domain maintainers.

## 2. Roles & Responsibilities
- **Principal Software Architect**: Overall system design, breaking changes, ADR approval.
- **Distinguished AI Engineer**: Context compilation algorithm, prompt lab, eval harness.
- **Staff Infrastructure Engineer**: CI/CD pipelines, release automation, performance benchmarks.
- **DevEx Lead**: CLI ergonomics, local dev container, linter rules, workspace configuration.
- **Documentation Architect**: Technical docs portal, cookbooks, learning paths.

## 3. Decision-Making Process
All major architectural changes require a formal Architecture Decision Record (ADR) submitted to `/docs/decisions/` and reviewed by the Architecture Council.
