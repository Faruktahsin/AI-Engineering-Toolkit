# AI Engineering Toolkit: Mission Statement

## Strategic Mission
To bridge the gap between academic AI research and production software systems engineering by providing zero-dependency context compilers, open-standard MCP servers, benchmarked prompt libraries, and hands-on learning systems.

## Core Operational Pillars
1. **Local-First Privacy**: Developers and enterprises retain total control over vector indexes and context graphs locally without forced cloud dependencies.
2. **Deterministic Precision**: Prompt preambles, token budgets, and memory retrieval must be predictable, reproducible, and verifiable down to single tokens.
3. **Open Ecosystem Parity**: Equal, first-class support for TypeScript (`@aiet/*`) and Python (`aiet-python`), open standards (MCP, SQLite, JSON Schema), and cloud-agnostic model routing.
4. **DevEx Obsession**: Sub-5ms latency, beautiful visual tools, zero-config setups, and documentation that acts as an interactive masterclass.

## Non-Goals
- **Not a heavy framework wrapper**: AIET does not attempt to replace low-level SDKs (OpenAI, Anthropic). It enhances them.
- **Not a proprietary SaaS trap**: Core context compilation, local PAKB storage, and CLI utilities remain open-source forever.
- **Not a low-code GUI for non-developers**: Built by engineers for engineers who write code.
