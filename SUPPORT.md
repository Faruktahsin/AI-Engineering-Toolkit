# PAKB Support & Community Resources

## Getting Help

If you encounter issues or have questions regarding the Personal AI Knowledge Base (PAKB):

1. **Documentation**: Read the [README.md](README.md) and architecture specifications in `docs/architecture/`.
2. **GitHub Discussions**: For general usage questions, Q&A, and ideas, use GitHub Discussions.
3. **Bug Reports**: If you find a bug, open an issue using the [Bug Report Form](.github/ISSUE_TEMPLATE/bug_report.yml).

## Supported Runtimes & Environments

- **Node.js**: `22.x` LTS or higher (`>=22.0.0`)
- **pnpm**: `9.x` or higher
- **SQLite**: `3.46.0` or higher
- **Operating Systems**: Linux (Ubuntu 22.04+), macOS (14.0+), Windows 11 (x64)
