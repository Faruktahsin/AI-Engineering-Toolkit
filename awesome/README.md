# Awesome AI Engineering Resources

A curated list of production-grade AI engineering tools, research papers, MCP servers, and context optimization frameworks.

## Model Context Protocol (MCP) Tools
- **[PAKB MCP Server](https://github.com/faruktahsin/AI-Engineering-Toolkit/tree/main/packages/mcp-server)**: Local-first context compiler and knowledge graph MCP server over stdio/SSE.
- **[Model Context Protocol Specs](https://modelcontextprotocol.io)**: Official Anthropic open standard specification.

## Context & Memory Engines
- **[PAKB (Personal AI Knowledge Base)](https://github.com/faruktahsin/AI-Engineering-Toolkit/tree/main/packages/pakb)**: Local-first 5-primitive knowledge graph engine on SQLite WAL.
- **[tiktoken](https://github.com/openai/tiktoken)**: Fast BPE tokeniser for use with OpenAI's models.

## AI Engineering Research Papers
- **Attention Is All You Need**: Transformer architecture foundation.
- **MemGPT**: Operating system paradigm for LLM long-term memory management.
