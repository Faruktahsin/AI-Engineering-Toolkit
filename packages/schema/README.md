# `@aiet/schema`

Canonical schema definitions, primitive interfaces, enums, and error classes for **AI Engineering Toolkit** and **PAKB**.

## Installation

```bash
pnpm add @aiet/schema
```

## Usage

```typescript
import {
  Entity,
  EntityType,
  SensitivityTier,
  PAKBError,
  PAKBErrorCode,
} from "@aiet/schema";
```
